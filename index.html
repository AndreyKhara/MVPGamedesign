Формат файлов

Юниты: обязательные колонки id,name,hp,attack,defense,cost; необязательные attack_speed (ударов/с, по умолчанию 1), crit_chance (0…1), crit_mult (≥1).

Лут: id,table_id,item,chance (шанс в процентах), необязательно rarity. Сумма шансов в каждой table_id должна быть 100%.

Разделитель — запятая или точка с запятой (определяется автоматически). JSON — массив объектов с теми же полями.

Редактор таблицы

Изменения сохраняются автоматически в localStorage.

Калькулятор урона / TTK

урон = max(атака − защита, атака × minRatio) × множитель; ожидаемый = урон × (1 + шанс_крита × (крит_множ − 1)); удары = ⌈HP / урон⌉; TTK = (удары − 1) / скорость_атаки

Если у юнита заданы колонки crit_chance/crit_mult/attack_speed, используются они.

Матрица TTK (секунды, ожидаемое значение)

Строка — атакующий, столбец — цель. Чем темнее, тем дольше бой.

Кривая прогрессии

опыт_до_след(L) = round(A × LB + C × L); стат(L) = round(база × (1 + g)L−1)

Проверка лута

Шансы в процентах. Для каждой таблицы дропа (table_id) сумма должна быть 100% (допуск ±0.01).

Симуляция дропов

Аудит баланса

сила = средний DPS против остальных юнитов × HP; эффективность = сила / цена; z = (эфф − среднее) / σ. z > k → доминирующий, z < −k → бесполезный

Симулятор инфляции

запасt = max(0, запасt−1 + доход × (1 + рост)t−1 − (фикс_сток + запасt−1 × %_сток))
