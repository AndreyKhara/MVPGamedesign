# Balance & Progression Studio

Статическое веб-приложение для проверки баланса игры: импорт таблиц статов, калькулятор урона/TTK, кривые прогрессии, проверка таблиц лута, экспорт в CSV/JSON. Сервер и база данных не нужны — всё работает в браузере, данные хранятся в `localStorage`.

**Демо:** https://andreykhara.github.io/MVPGamedesign/

## Модули

| № | Вкладка | Что делает |
|---|---------|-----------|
| 1 | Импорт | Загрузка CSV/JSON через выбор файла или drag&drop. Проверяет обязательные колонки, числовые типы, диапазоны и дубли ID; при ошибках файл не импортируется, а показывается список ошибок с номерами строк. Разделитель `,` или `;` определяется автоматически. |
| 2 | Таблица | Редактирование ячеек, добавление/удаление строк и колонок, фильтр, подсветка некорректных значений, автосохранение в `localStorage`, экспорт CSV/JSON. |
| 3 | Урон / TTK | Урон за удар, криты, DPS, число ударов и время до убийства для пары «атакующий → цель» с пошаговым расчётом; матрица TTK «все против всех»; сверка с симуляцией. |
| 4 | Прогрессия | Формула опыта с настраиваемыми коэффициентами, таблица уровней, рост стата, график (Chart.js), пресеты, экспорт. |
| 5 | Лут | Проверка суммы шансов = 100% в каждой таблице дропа, подсветка ошибок (не число, < 0, > 100, 0%), нормализация, симуляция N дропов, экспорт отчёта. |
| + | Аудит | Поиск доминирующих и бесполезных юнитов по показателю «сила / цена» (z-оценка). |
| + | Инфляция | Источники и стоки ресурса, прогноз на N шагов, график. |

Ещё: тёмная тема, адаптивная вёрстка, горячие клавиши (`Alt+1…7` — вкладки, `Ctrl+S` — экспорт всего проекта в JSON, `Alt+T` — тема, `Alt+N` — новая строка).

## Формулы

**Урон:** `урон = max(атака − защита, атака × minRatio) × множитель`
`minRatio` (по умолчанию 0.1) не даёт защите полностью обнулить урон — слабый юнит всё равно наносит 10% атаки.

**Криты:** `ожидаемый урон = урон × (1 + шанс_крита × (крит_множ − 1))`

**TTK:** `удары = ⌈HP / ожидаемый урон⌉`, `TTK = (удары − 1) / скорость_атаки`
Первый удар происходит в момент 0, поэтому цель, убитая с одного удара, имеет TTK = 0. Дополнительно показываются худший (без критов) и лучший (все удары — криты) случаи.

**Прогрессия:** `опыт_до_след(L) = round(A × L^B + C × L)`, `стат(L) = round(база × (1 + g)^(L−1))`
`B = 1` и `A = 0` дают линейную кривую, `B > 1` — ускоряющуюся.

**Аудит:** `сила = средний DPS против остальных × HP`, `эффективность = сила / цена`, `z = (эфф − среднее) / σ`; `z > k` — доминирующий, `z < −k` — бесполезный.

## Формат данных

Юниты (`data/units.csv`, `data/units_crit.csv`):

```
id,name,hp,attack,defense,cost[,attack_speed,crit_chance,crit_mult]
1,Мечник,120,25,10,100
```

Лут (`data/loot.csv`) — шанс в процентах, сумма по каждой `table_id` должна быть 100:

```
id,table_id,item,chance[,rarity]
1,goblin,Медная монета,55,common
```

В `data/loot.csv` таблица `chest` намеренно содержит ошибку (сумма 95%) — для демонстрации проверки. Файлы в `tests/invalid_*.csv` — примеры некорректных данных для проверки валидации.

JSON — массив объектов с теми же полями (или объект, в котором есть такой массив).

## Запуск локально

Вариант 1 — просто открыть `index.html` в браузере (двойной клик). Всё работает, кроме графиков без интернета: Chart.js грузится с CDN.

Вариант 2 — локальный сервер (нужен Node.js):

```bash
node tools/serve.js 8080
```

и открыть http://localhost:8080.

## Тесты формул

```bash
node tests/run-tests.js
```

30 проверок: урон, криты, TTK, скорость атаки, прогрессия, сумма лута (включая ошибку округления `0.1 + 0.2`), разбор CSV с `;` и кавычками, валидация, экспорт → импорт без потерь. Ожидаемые значения посчитаны вручную.

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub и загрузить файлы проекта (`index.html` должен лежать в корне).
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
